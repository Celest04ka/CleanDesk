# CleanDesk

[English](README.md) | **Русский**

Маленькая программа в трее для чистого, минималистичного рабочего стола. Горячая клавиша прячет панель задач или значки рабочего стола, повторное нажатие возвращает их.

| Действие | Клавиша по умолчанию |
|---|---|
| Скрыть / показать панель задач | **Ctrl+Alt+L** |
| Скрыть / показать значки рабочего стола | **Ctrl+Alt+K** |

В Windows есть встроенное «Автоматически скрывать панель задач», но с ним панель выезжает каждый раз, когда мышь касается нижнего края экрана. С CleanDesk панель остаётся скрытой, пока не нажмёшь клавишу снова, а развёрнутые окна занимают весь экран.

## Возможности

- Значки рабочего стола переключаются так же, как *ПКМ по рабочему столу → Вид → Отображать значки рабочего стола*.
- Горячие клавиши задаются в обычном текстовом файле и применяются сразу после сохранения.
- Можно включить запуск вместе с Windows.
- Без установки и зависимостей. Это один exe примерно на 130 КБ, ему нужен только .NET Framework 4, который уже есть в Windows 10 и 11.

- **Ctrl+Alt+L** прячет или показывает панель задач. Левый клик по значку в трее делает то же самое.
- **Ctrl+Alt+K** прячет или показывает значки рабочего стола.
- Правый клик по значку открывает меню: оба переключателя, **Настройки…**, **Запускать вместе с Windows** и **Выход**.
- При выходе панель задач возвращается. Значки рабочего стола — обычная настройка Windows, поэтому после выхода они остаются в том же состоянии.

## Настройки

При первом запуске рядом с exe появляется `CleanDesk.ini`. Его можно открыть и из меню в трее → **Настройки…**. После сохранения файла CleanDesk применит изменения в течение секунды, перезапускать ничего не нужно.

```ini
; Язык программы: auto (как в Windows), en или ru
Language = auto

; Запускать CleanDesk вместе с Windows: yes или no
StartWithWindows = no

; Скрыть / показать панель задач
Taskbar = Ctrl+Alt+L

; Скрыть / показать значки рабочего стола
DesktopIcons = Ctrl+Alt+K
```

- Клавиша записывается как модификаторы плюс одна обычная клавиша: `Ctrl+Alt+L`, `Ctrl+Shift+F1`, `Win+Alt+H`, `F9`…
- Модификаторы: `Ctrl`, `Alt`, `Shift`, `Win`.
- Клавиши: `A`–`Z`, `0`–`9`, `F1`–`F24`, `Space`, `Enter`, `Tab`, `Esc`, `Backspace`, `Insert`, `Delete`, `Home`, `End`, `PageUp`, `PageDown`, стрелки (`Up`, `Down`, `Left`, `Right`), `NumPad0`–`NumPad9`, `Pause`, `PrtSc` и знаки ``- = [ ] ; ' , . / \ ` ``. Сам плюс пиши словом `Plus`.
- Буквы означают физические клавиши, поэтому можно писать и по-русски: `Ctrl+Alt+Д` — то же, что `Ctrl+Alt+L`.
- `none` отключает действие.
- Если в записи ошибка или комбинацию уже заняла другая программа, придёт уведомление с причиной. Если в этот момент панель скрыта, она сразу вернётся, чтобы не остаться без клавиши.

## Сборка из исходников

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат — `bin\CleanDesk.exe`. Ставить ничего не нужно: компилятор C# (`csc.exe`) входит в .NET Framework 4.x и уже есть в Windows. Значок — `assets/icon.ico`. Его рисует скрипт `assets/make-icon.ps1`, так что значок можно поменять там и перерисовать.

## Как это устроено

- **Панель задач.** При скрытии включается обычное *автоскрытие*, поэтому рабочая область становится на весь экран. Окна панели (`Shell_TrayWnd`, `Shell_SecondaryTrayWnd`) прячутся через `ShowWindow(SW_HIDE)`, поэтому выехать не могут. Пока панель скрыта, сторож прячет её снова, если Проводник её вернул. При показе исходная настройка автоскрытия восстанавливается. Пока панель скрыта, эта настройка хранится и в `HKCU\Software\CleanDesk`, на случай аварийного закрытия.
- **Значки рабочего стола.** CleanDesk посылает окну рабочего стола Проводника (`SHELLDLL_DefView`) тот же `WM_COMMAND` (`0x7402`), что и пункт меню *Отображать значки рабочего стола*.
- **Горячие клавиши.** Через `RegisterHotKey`. `CleanDesk.ini` перечитывается, когда меняется время его изменения.
- **Автозапуск.** Строка в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
